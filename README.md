# Unity Video Materials

A boilerplate Unity project for using video files as dynamic materials on 3D objects.

The project provides a starting point for integrating MP4 video textures into Unity scenes, enabling moving images to be applied to 3D geometry and used within interactive environments, real-time visuals and immersive experiences.

## Features

- **Video textures** — Use MP4 files as moving image materials.
- **3D surfaces** — Apply video playback to materials on scene geometry.
- **Reusable setup** — A starting point for video-based visual experiments and interactive projects.

## Built With

- [Unity](https://unity.com/)
- C#
